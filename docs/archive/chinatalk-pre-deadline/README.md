# ChinaTalk pre-deadline package

This index describes the status, screening, preflight, promotion, and
composition-smoke prose from the experiment-first phase of the ChinaTalk work.
It explains how the project reached the deadline pivot, but it is not a current
run instruction and does not establish a completed live DATE evaluation.

The active submission is governed by the current
[Packet](../../contest/README.md), [evidence matrix](../../contest/EVIDENCE_MATRIX.md),
and [deadline pivot](../../contest/adr/0075-cut-the-experiment-and-package-the-evidence-boundary.md).

## Contents in the broader public repository

- `CURRENT_DESIGN.md` and `CURRENT_STATUS.md` record the pre-pivot active state.
- `M2_*` and `M3_*` record dry-run, screening, preflight, and promotion work.
- `COMPOSITION_SMOKE.md` records the closed-world composition smoke.

Machine-readable `MODEL_*`, `STUDY_MANIFEST.*`, and supporting measurement
fixtures remain at their stable `docs/contest/` paths because the runnable test
suite loads them directly. Their location is a compatibility boundary, not a
claim that the earlier experiment-first sequence remains active.

The curated contest export includes this index but omits the archived
preflight and promotion files. The broader public repository retains their
contents and Git history.

The original layout is available at public commit
[`236090758a11e58fd4d882f625f7db093121faba`](https://github.com/glennmatlin/wopr/tree/236090758a11e58fd4d882f625f7db093121faba/docs/contest).
