# Sounding is 18 games plus one Overlay Demo

Status: accepted historical decision; superseded by the locked DATE pivot recorded in draft ADR-0010

The Sounding is 3 Organizational Presets × 2 retained models × 3 matched seeds = 18 games, Overlay off. One additional Demo game turns Overlay on. Seeds are 51, 52, 53, disjoint from screening 101–103 and preflight 91–93. Models remain DeepSeek V4 Flash and GPT-OSS 20B.

Five seeds (30 games) were rejected as leftover factorial habit. A one-model Sounding was rejected because the Instrument would look model-specific.

Default Release parameters, unless a later ADR changes them: presidential staff uses sole authority with deference 0; equal council uses equal weights and threshold two-thirds; chair-weighted council uses weights 2, 1, 1 and the same two-thirds threshold, so the chair plus one other bind and the two staff cannot bind the chair.
