# Combine matched and endogenous pressure in Cycle 2

Status: accepted decision D54, refined by D55 and clarified by D62; partially resolves OPEN-WORLD-002 and OPEN-RUN-003

Every normal first-episode run that reaches the Cycle 1 boundary receives one frozen Matched Pressure Inject before Cycle 2, in addition to the endogenous consequences of its own U.S. policy, counterpart decisions, non-action, and delay. The inject's identity, trigger, exogenous fact, entitled U.S. observation, timing, and direct authored patch are fixed across matched runs. Endogenous consequences remain policy-dependent and may diverge.

## Considered options

- Combine one common frozen exogenous inject with endogenous consequences.
- Let Cycle 2 depend only on endogenous consequences.
- Replace policy-dependent consequences with one fully authored second-cycle trajectory.

Endogenous-only play preserves causal freedom but may give compared Rooms no common adaptation pressure or an institutionally thin second cycle. A fixed trajectory improves superficial comparability by severing the relationship between Cycle 1 choices and Cycle 2 state. The hybrid holds one challenge constant while retaining the consequences that make actions matter.

## Consequences

Cycle 1 endogenous consequences close first. The Matched Pressure Inject then executes at the frozen transition barrier, and Cycle 2 inputs preserve common-inject facts and policy-dependent consequence facts as separate provenance layers. The inject MUST be authored on a state axis whose preconditions hold across every admissible nonterminal Cycle 1 branch; it MUST NOT reset divergent state, contradict admitted consequences, reveal hidden intent, prescribe policy, or repair a weak run.

If a normal run cannot admit or deliver the frozen inject as specified, the matched comparison is invalid rather than silently unmatched. A run that has already reached a substantive World terminal ends validly without receiving it. The exact inject content remains Setup-authoring work, and its event, observations, State Patch when required, applicability, and delivery must be sealed before model outputs are observed.

Endogenous-only and fully scripted Cycle 2 profiles remain preserved as explicit evaluation alternatives, not Crisis Setups or Seeds. D55 selects High-Altitude Access Degradation as the first inject class. D62 clarifies that matched bytes belong to the frozen event and patch templates, while each admitted entry and patch instance binds its run's actual Core version and hash; otherwise open prior branches would make a fixed base version stale. The existing harness does not implement this hybrid DATE transition, so D54-D62 remain design rather than execution evidence.
