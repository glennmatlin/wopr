# Organizational Presets, optional Overlay

Status: accepted historical decision; superseded by the locked DATE pivot recorded in draft ADR-0010

The three Presets are Organizational types: presidential staff (sole release), equal council, and chair-weighted council. All use full press. A fictional Overlay of chair text, doctrine, and personality may be laid over those chairs. Real country and command-system names are forbidden. Overlay is a harness switch, not an engine feature. The World stays Overlay-blind.

Pre-delegated / `distributed` is rejected as Preset 3. Country-named prompt packs are rejected as Presets. Using Overlay as the primary object of evaluation is rejected.

Consequence: Identity already accepts extra string fields, so Overlay on/off is prompt composition. Weighted council uses existing council weights. PROTOCOL still names the old 2×2 until amended. Whether the Sounding runs Overlay off, on, or both is not decided here.
