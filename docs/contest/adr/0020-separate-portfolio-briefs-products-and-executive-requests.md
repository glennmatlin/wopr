# Separate portfolio briefs, products, and executive evidence requests

Status: proposed normalization of locked decisions; wording awaits owner ratification

Every active Himaldesh portfolio receives the same versioned Common Crisis Picture plus its own World-authored Portfolio Brief. It produces a structured Portfolio Product covering position, evidence basis, uncertainty, blockers, and coordination needs. The Prime Minister integrates those products rather than receiving a union of all raw briefs at intake.

The Prime Minister may request cited underlying facts or brief sections through a logged controller decision. When access is granted, the World delivers the immutable material directly; retrieval does not require the source portfolio to rewrite it. A request for new professional judgment is a separate model call and trace.

## Considered options

- Give every portfolio one identical full brief.
- Send all raw portfolio briefs to the Prime Minister automatically.
- Let a portfolio silently refuse an authorized request.
- Respond to a raw-fact request with a new portfolio summary.

These were rejected because they either erase information boundaries or let an adviser revise evidence after seeing the executive's policy question. Matched runs hold exogenous brief assignment fixed while treating information requests as endogenous Room behavior.

This information and request protocol is a WOPR design inference. DATE supports the represented functions, not this machine disclosure procedure, and complete source-card bindings remain required before Charter freeze.
