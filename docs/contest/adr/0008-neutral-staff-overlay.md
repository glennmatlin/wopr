# Demo Overlay is Neutral Staff

Status: accepted historical decision; superseded by the locked DATE pivot recorded in draft ADR-0010

The Demo trajectory uses Overlay pack `neutral_staff`: Chair, Operations, and Dissent. Member ids stay executive, strategic_advisor, and risk_advisor. Seat labels drop the four commander personalities. No country names.

A four-polity Overlay and owner-authored country packs were rejected. Sounding manifests still require Overlay off. `STUDY_MANIFEST.room_instrument_demo.candidate.json` is the one-cell Demo template and is not live approval. Demo attempts record `overlay_pack_hash`; that digest must match `overlay_pack_hash()` or the manifest is rejected.
