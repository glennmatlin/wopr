# Overlay off in the Sounding, on in the Demo

Status: accepted historical decision; superseded by the locked DATE pivot recorded in draft ADR-0010

The Sounding runs the three Organizational Presets with Overlay off, so a reviewer can read the Release rule without a story pack. The Demo trajectory turns Overlay on so the lab looks inhabited. Overlay is not a Sounding factor.

Running Overlay on and off for every Preset was rejected as a six-cell grid. Running Overlay on for every Sounding game was rejected because structure and story would be mixed in every artifact.

Consequence: cell count is Presets times models times seeds, plus one Demo game. Seed and model counts are not fixed here.
