# Use abstract fictional force packages for the first episode

Status: accepted decision D52; refined by D53; partially resolves OPEN-WORLD-002

The first ridge-seizure Setup represents the Olvanan occupation and Himaldeshi recapture capability as a small roster of named fictional Force Packages. Each package exposes only episode-relevant ownership, function, location and control, posture and readiness, access and support dependencies, and broad capability bands. The geography contains the ridge, adjacent logistics node, and only the approaches or access routes needed to adjudicate control, support, movement, and operational friction.

## Considered options

- Use abstract fictional Force Packages at operational resolution.
- Author a formation-level fictional order of battle with named systems, stocks, ranges, routes, and detailed logistics.
- Use strategic-only tokens for occupation, recapture readiness, and the decision clock.

Formation-level detail would consume authoring and validation effort, invite false precision, and move the contest entry away from the U.S. Room. Strategic-only tokens would not support the selected request's planning, logistics, defensive materiel, force-protection, intelligence-sharing, and access dependencies or permit useful consequence validation. The selected middle resolution preserves those decision pressures without claiming weapon-level realism.

## Consequences

Force Packages are World entities and affordances, not a legal-move menu or a restriction on Open Action Proposals. State Patches may change their existing D51 fields and relations, but EXCON may not invent a package, capability band, access path, or support resource to make a proposal succeed. The U.S. remains excluded from target selection, fires, and combat-force participation in this first Setup; only U.S. or third-party noncombat resources that materially affect the selected support choices need typed representation.

Module 13 supplies a reversible default package roster, names, initial values, fictional geography, report references, and support-resource mapping under D60. A formation-level or strategic-token representation remains available as a separately versioned World-resolution profile, not an alternate Seed. Changing the resolution schema changes the World and Room-World Contract; changing a default package identity or initial state increments the Setup profile version and, after freeze, creates a new Setup or run identity.

This is a documentation decision, not evidence that the DATE World, Force Packages, EXCON, or validator can execute. D53 fixes the two-cycle Episode Horizon within which the packages must transition. The first tracer must instantiate and transition the selected abstraction before any runnable claim.
