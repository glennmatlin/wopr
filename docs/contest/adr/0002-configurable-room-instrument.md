# Packet job is a configurable Room Instrument

Status: accepted historical decision; superseded by the locked DATE pivot recorded in draft ADR-0010

The ChinaTalk Packet is a configurable Room Instrument on the Nuclear War World, in the GenWar Sim / GenWar TTX split: the model sits in chairs, the World owns consequences, a reviewer inspects votes. The Sounding is two or three named Presets, not a 2×2 factorial and not four different org charts in one game.

A journal-style 40-cell profile was rejected as the wrong object for this contest. A mixed-structure showcase in a single game was rejected because the judge cannot tell which Room caused the outcome. One matched contrast only was rejected as too thin for the lab story.

Consequence: every game uses one Preset for all four Rooms. Presets change across games on matched seeds. PROTOCOL still describes the old factorial until it is amended. Chair text, press, and the exact Preset list are not fixed by this ADR.
