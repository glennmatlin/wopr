# Source-rights register

Status: owner-reviewed for the 2026-09-01 public contest release

This register supplies the redistribution treatment that complements the
machine-readable source cards. The source cards retain each source's issuing
institution, public title, URL, retrieval date, available publication date,
faithful claim paraphrase, and fact and inference bindings. This register does
not grant ownership of, or imply endorsement by, any linked institution.

## Treatment code

`T1` permits publication of the source URL, issuing institution, title,
available date metadata, and WOPR-authored faithful paraphrase. The curated
release does not include downloaded copies, screenshots, or substantial
verbatim excerpts from these sources. A future quotation must remain short,
attributed, and independently reviewed before publication.
