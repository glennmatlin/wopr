01 / Research question

Measure the Room, not a new game.

The Packet asks whether an inspectable command process changes when the Organizational type changes and the World stays fixed. Four Rooms share one Preset in each game. Seeds are matched across Presets. The output is seed-level votes and outcomes, not a leaderboard.

Nuclear War is a controlled World. It is not a model of any real country’s command system and does not estimate real-world launch probability.

03 / Why this extends the existing work

The contest contribution is a Room you can configure and audit.

The contest examples cover scenario benchmarks, historical counterfactuals, and strategic games. WOPR contributes a different seam: the World owns consequences, the Room is a named Organizational type, and member votes stay attached to the replay.

01

Same World, different Room

The initial state and engine seed are paired across Presets. Differences can be traced to the Organizational type, not to a new scenario.

02

Inspectable command process

Every member vote, selected action, aggregation rule, private trace, and failure prefix is retained in a validated sidecar.

03

Process first, not a score

The output is seed-level dissent, bind or override, ordinary versus forced escalation, and outcomes. Overlay is Demo only.

06 / Boundaries

What this evaluation does not claim.

  • Not nuclear doctrine. The game supplies a controlled action space; it does not reproduce a national command system.
  • Not launch propensity. Ordinary launches are downstream of queue and targeting choices; forced final strikes are scored separately.
  • Not model ranking. Three matched seeds support a Sounding, not population estimates or a single score.
  • Not complete coverage. Six terminal failures leave five matched pairs, and the Overlay Demo has no admissible trajectory.
